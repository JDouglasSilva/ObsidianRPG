# Atributos — Introdução

> [!tip]+ Atributos Primários
> Atributos Primários são os **principais valores do personagem**.
>
> - Determinam **dano de ataques**, **vida**, **magia** e **capacidade física ou mental**.
> - Você ganha **+1 ponto de Atributo Primário a cada nível**.
>
> Esses atributos podem ser usados em **situações de roleplay** e desafios fora de combate.
> Exemplos de uso em jogo
>- **Força:** arrombar portas, levantar objetos pesados.
>- **Inteligência:** perceber detalhes, resolver enigmas.
>- **Destreza:** escalar paredes, executar tarefas delicadas.
>
>Atributos também afetam o combate, Armas, escudos, arcos, bestas, varinhas ou cajados, usam diferentes atributos para causar dano ou seu efeito em questão.

> [!info]+ Como funcionam os atributos
> - Ao começar o jogo, todos os personagens possuem **1 em todos seus Atributo Primário**.
> - Além disso, recebem **3 pontos adicionais para distribuir livremente** entre os atributos.
> - A cada **nível ganho**, o personagem recebe **+1 ponto de atributo** para evoluir seus atributos.

## Atributos Primários

| Atributo               | Função                                                                                               |                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------- |
| **Força (FOR)**        | Importante para **armas pesadas** e combate corpo a corpo com armas grandes                          |                             |
| **Inteligência (INT)** | Importante para **armas mágicas** e determina seu **[[RPG/dicionario#^poder-magico\|Poder Magico]]** | Poder Mágico]] = 25 + D25** |
| **Destreza (DEX)**     | Importante para **armas rápidas** e **armas de longa distância**                                     |                             |
| **Vitalidade (VIT)**   | Aumenta a vida em **50 + D50** *(Todos os personagens começam com 100 de vida)*                      |                             |
